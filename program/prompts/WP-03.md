## Steps

   `kLayoutVersion` (= 1) and `kBulkSegmentSuffix`. Pick `kMagic` as four ASCII
   letters read as a little-endian `uint32_t` and `kBulkSegmentSuffix` as a
   short string; state both values in your report. For each struct:
   `static_assert` its size (and alignment); for every `std::atomic` member
   type, `static_assert(...::is_always_lock_free)`. Offset functions — one
   function per part, computed only here: description offset, cycle slot `i`

   locks, no clock, no I/O.
2. **Slot helpers** (`IMP-0009`): `beginSlot` (sequence to odd, release fence),
   `endSlot` (sequence to the next even value, release store), and `tryCopySlot`

   larger than the room after the header; copy the payload to the caller's
   buffer; acquire fence; re-read the sequence; return false if it changed).
   Give each one a short comment stating its memory-order reason. They work for
   both cycle and bulk slots.
3. **Attach check** (`IMP-0010`): `checkAttach(const MeasStatus&)` returning an
