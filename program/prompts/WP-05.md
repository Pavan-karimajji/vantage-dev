## Steps
1. **Test environment (owner decision).** Never install into

   `py -3.12 -m venv C:\ws\venvs\rct-pytest`, then install `pytest` and
   `PyYAML` into it with its own pip. Report the versions. Run every Python
   test of this package with `C:\ws\venvs\rct-pytest\Scripts\python.exe -m pytest`.
   First run the three existing files in `tests/python/` and report the result
   before writing anything (this is the gap WP-01 recorded).
2. **`check_rct_schema.py`**, one script, three modes, house style of
   `check_signal_header.py` (reuse its `find_protoc` and wire reader by import,
   do not copy them):
   - `--fields` (`IMP-0016`, `ANL-01`): parse the *Message fields* tables of the
     design document; compile the package's protos to a descriptor set; compare
     every message and enum both ways (name, number, type, label; enum values by
     name and number). A table row with no descriptor field, or a field with no
     table row, is a finding.
   - `--compat <git-ref>` (`IMP-0017`, `ANL-02`): build the descriptor set of
     the protos at `<git-ref>` from `git archive` into a temp folder; compare
     every field and enum value of every message present at the base, by number.
     The only allowed differences are the two retirements (`SignalHeader` field 5,
     `CompState.State` value 4). The 1.0.0 base is `83b7fe9`.
   - `--reserved` (`IMP-0018`, `ANL-03`): both retirements are reserved by number
     and by name in the descriptors; then compile a temp proto that reuses
     `SignalHeader` field 5 and require `protoc` to refuse it.
   Exit 0 = holds, 1 = findings, 2 = could not run.
3. **`check_signal_header.py --message <name>`** (`IMP-0019`, `ANL-04`):
   repeatable; each named message is checked as a port payload beside those
   found in `conf/ports.yaml`. Minimal diff: add the option, change nothing else.
4. **`check_livemeas_layout.py --root <dir>`** (`IMP-0020`, `ANL-05`): repeatable;
   finds every definition of `MeasStatus`, `CycleSlotHeader`, `BulkSlotHeader`
   in C, C++ and Python `ctypes` sources under the roots (skip build output and
   `.venv*` folders); passes only if exactly one file defines them and that file
   `static_assert`s each one's size. It prints the roots it searched.
5. **`tests/python/test_rct_checks.py`** (`IMP-0021`): for each of `ANL-01`..`ANL-05`
   a `.c1` (the real tree passes) and a `.c2` (the planted violation of the test

   `modules/interfaces` and, when they exist beside it, `../vantage` and
   `../vantage-lab`, and says which roots it searched. File header block.
6. **Run the checks on the real tree** (exit check below) and fix only your own
