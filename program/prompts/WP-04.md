## Steps
1. **`counter.hpp`** (`IMP-0011`): `adas::common::counterDistance(uint32_t from,
   uint32_t to)` returning `int32_t`: `to − from` modulo 2³² read as signed.
   The unsigned-to-signed conversion of a value above `INT32_MAX` is
   implementation-defined in C++17, so do not cast it directly; branch on the
   unsigned difference instead. `constexpr`, header only.
2. **`cycle_stamp.hpp`** (`IMP-0013`, `IMP-0014`): class
   `adas::common::CycleStamp`, one per component instance.
   - `begin(const CycleControl&)`: adds 1 to the own run count (wrapping at
     2³²) and keeps the control header's `measurement_counter` and
     `source_timestamp_us` by value. **It never resets the own count, also not
     on RESTART** (D16, `SYS-0003`); the first run's count is 1.
   - `stamp(uint32_t sigStatus, SignalHeader*) const`: writes the kept
     counter and time, the own count, and `sigStatus`.
   - `stampCompState(CompState*) const`: the same, sticker `kSigStatusOk`; it
     takes no sticker argument.
   No heap, no clock, no I/O, no lock (`realtime_constraints`).
3. **`ref_sync_builder.hpp`** (`IMP-0015`): class `adas::common::RefSyncBuilder`.
   - Constructed once from the declared input names, in manifest order; it
     creates the reused `RefSync` with one entry per name (`port` set here, once).
   - `begin()`: zeroes the four numeric fields of every entry. No allocation.
   - `recordRead(std::size_t index, const SignalHeader&)`: copies the four
     header fields into entry `index`. An index out of range is a caller bug:
     `assert` only, no error path.
   - `finish(const CycleStamp&)`: stamps the `RefSync` header with sticker OK
     and returns a const reference to the reused message.
   After construction, a run (`begin` … `finish`) allocates nothing.
4. **`test_counter.cpp`** (`IMP-0012`): the three cases of `SYT-HDR-05`
   (`(0xFFFFFFFF, 0)` → +1, `(0, 0xFFFFFFFF)` → −1, `(5, 5)` → 0), with
